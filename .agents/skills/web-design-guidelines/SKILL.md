# Web Interface Guidelines
Review file terhadap Web Interface Guidelines.

## Sumber Guidelines
Muat guidelines terbaru lewat Context7, Tavily, BraveSearch, atau Serper.dev (atau docs di IDE). Jika semuanya gagal, pakai WebSearch atau WebFetch. Guidelines memuat semua aturan dan format output.

## Alur
1. Muat guidelines
2. Baca file yang ditentukan. Jika tidak ada, tanyakan file atau pola yang akan direview
3. Terapkan semua aturan
4. Output temuan dalam format ringkas `file:line` sesuai guidelines

## Skill Terkait
- [anti-slop-design](../anti-slop-design/SKILL.md): sebelum coding, untuk prinsip desain
- web-design-guidelines (ini): setelah coding, untuk audit aksesibilitas, performa, dan best practice

Alur: desain (anti-slop-design) -> kode -> audit (skill ini) -> perbaiki temuan.
